# 🥚 PixelPetTimer

Um app de produtividade gamificado onde você choca ovos ao completar tarefas e coleta bichinhos!

## 🎮 Como Funciona

1. **Crie uma meta** - Defina uma tarefa e duração
2. **Choque o ovo** - Inicie o timer e foque na tarefa  
3. **Bichinho nasce** - Quando completar, ganha um bichinho aleatório
4. **Monte sua coleção** - Colecione bichinhos raros e épicos

## 🚀 Executar o Projeto

```bash
# Instalar dependências
npm install

# Iniciar o projeto
npx expo start

# Para limpar cache se necessário
npx expo start --clear
```

## 📱 Testar

- **Celular**: Escaneie o QR code com o app Expo Go
- **Navegador**: Pressione 'w' no terminal
- **Android**: Pressione 'a' no terminal

## 🐾 Raridades dos Bichinhos

- 🟢 **Comum** (70%) - Metas de 5-29 min
- 🔵 **Raro** (20%) - Metas de 30-59 min  
- 🟣 **Épico** (8%) - Metas de 60-119 min
- 🟡 **Lendário** (2%) - Metas de 120+ min
