# Instruções para Imagens

Esta pasta contém as imagens dos ovos e bichinhos do PixelPetTimer.

## Estrutura de Pastas:
- `/ovos/` - Imagens dos ovos por raridade
- `/bichinhos/` - Imagens dos bichinhos coletáveis

## Formato das Imagens:
- **Formato**: PNG com fundo transparente
- **Tamanho**: 128x128 pixels (recomendado)
- **Resolução**: @1x, @2x, @3x para diferentes densidades de tela

## Ovos Necessários:
- `ovo-comum.png` - Ovo simples, cor neutra
- `ovo-raro.png` - Ovo com brilho azul
- `ovo-epico.png` - Ovo com brilho roxo
- `ovo-lendario.png` - Ovo dourado com efeitos especiais

## Bichinhos por Raridade:

### Comuns (70% chance):
- `gatinho.png` - Gatinho fofo
- `cachorrinho.png` - Cachorrinho amigável  
- `passarinho.png` - Passarinho colorido
- `coelhinho.png` - Coelhinho saltitante
- `hamster.png` - Hamster pequenino

### Raros (20% chance):
- `unicornio.png` - Unicórnio mágico
- `phoenix.png` - Fênix flamejante
- `dragao.png` - Dragão amigável
- `fada.png` - Fada brilhante

### Épicos (8% chance):
- `leao-dourado.png` - Leão majestoso
- `aguia-real.png` - Águia imponente
- `lobo-lunar.png` - Lobo místico

### Lendários (2% chance):
- `cosmic-cat.png` - Gato cósmico
- `stellar-bird.png` - Pássaro estelar
- `time-guardian.png` - Guardião do tempo

## Dicas de Criação:
1. Use cores vibrantes e elementos pixel art
2. Adicione pequenos detalhes que indiquem a raridade
3. Mantenha o estilo consistente entre os bichinhos
4. Para lendários, use efeitos especiais (brilho, partículas)

## Ferramentas Recomendadas:
- Aseprite (pixel art)
- Photoshop
- GIMP (gratuito)
- Piskel (online, gratuito)

## Exemplo de Nomeação:
```
/ovos/
  ovo-comum.png
  ovo-comum@2x.png
  ovo-comum@3x.png

/bichinhos/
  gatinho.png
  gatinho@2x.png  
  gatinho@3x.png
```
